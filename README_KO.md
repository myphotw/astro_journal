# AstroJournal UI Design Assets

이 패키지는 AstroJournal UI 개편을 위한 시각 디자인 참고 및 이미지 자산입니다.

## 구성

- `assets/home_hero_milkyway.png`
  - 홈 화면 상단 히어로 배경 이미지
  - 16:5 비율의 와이드 이미지
  - 왼쪽은 인사말/요약 텍스트를 올릴 수 있도록 비교적 어둡게 구성
  - 오른쪽은 은하수와 망원경 실루엣으로 시각적 포인트 제공
- `design_reference_sheet.png`
  - 전체 UI 분위기와 메뉴/카드/버튼 스타일을 설명하는 참고 시안
  - 실제 UI 요소를 잘라서 그대로 사용하지 말고 디자인 참고용으로만 사용

## 권장 적용

1. `assets/home_hero_milkyway.png`를 Flutter 프로젝트의 이미지 자산으로 등록합니다.
2. 홈 상단 배경에만 우선 적용합니다.
3. 텍스트 가독성을 위해 이미지 위에 좌측에서 우측으로 투명도가 변하는 짙은 네이비 오버레이를 적용합니다.
4. 사이드바, 카드, 버튼은 이미지로 만들지 말고 기존 UI 프레임워크의 컴포넌트로 구현합니다.
5. 메뉴 아이콘은 일관된 선형 SVG/아이콘 세트를 사용합니다.
6. 실제 천체 사진과 사용자 데이터는 이 배경 이미지로 대체하지 않습니다.

## 레이아웃 원칙

- PC: 왼쪽 고정 사이드바 + 콘텐츠 영역
- 홈의 첫 번째 정보 그룹: 관측 요약 + 시간대별 기상정보
- 홈의 두 번째 정보 그룹: 오늘 밤 추천 관측대상 + 촬영 스케줄
- 하단 참고 그룹: 최근 촬영 사진 + 다가오는 천문 이벤트
- 모바일: 동일한 정보 우선순위를 유지하고 세로 흐름으로 재배치

## 주의

이 패키지는 이미지 자산과 디자인 가이드입니다. 실제 UI 구현, 아이콘 상호작용, 반응형 레이아웃은 코드로 구현해야 합니다.
기존 DB/API/Outbox/동기화 로직과 기능 동작은 별도 승인 없이 변경하지 않습니다.
